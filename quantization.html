量化特性

量化是把高比特张量映射到低比特表示，从而降低显存与带宽消耗。MindIE-LLM 在权重 / 激活 / KV Cache 三个维度都提供了多种量化方案，并支持 不同量化方式的叠加。

总览

   方向     │  纯权重     权重+激活     KV Cache    稀疏化
   ─────────┼─────────────────────────────────────────────
   高精度   │   W8A16     ──────       FP16/BF16   ────────
   主流     │   W8A8                   KV Int8
   极致压缩 │   W4A8 mix              Attention/FA3 量化
   稀疏     │                                       W8A8SC
                                                   W16A16SC
   预处理   │   离群值抑制 (Anti-Outlier)
   阶段化   │   PD MIX 量化（prefill / decode 不同方案）

离群值抑制（Anti-Outlier）

激活张量中常出现少量超大值（outlier），它们会主导量化范围导致大部分数值精度受损。 离群值抑制通过等效平移与缩放把权重的部分尺度迁移到激活上，使 激活分布更平滑，再做量化。

  • 核心思想：y = (W·s) · (x/s)，s 是按通道学到的缩放因子。
  • 典型搭配：W8A8、W4A8 等激活也参与量化的方案。
  • 实现位置：权重侧离线工具 + 推理侧量化层。
  • 价值：在不增加推理时算力的前提下显著降低量化精度损失。

W8A8 量化

把权重和激活都量化为 int8。

  • 计算：matmul_int8 算子直接吃量化输入，结果再反量化。
  • 显存收益：权重显存约降至 1/2（fp16→int8）。
  • 吞吐收益：int8 矩阵乘可享受更高峰值算力。
  • 精度风险：激活量化最敏感，建议叠加离群值抑制。
  • 典型场景：吞吐为先的在线服务。

W4A8 混合量化

对模型不同层级采用不同量化方式：权重按敏感度选择 4 bit / 8 bit，激活统一 8 bit。

  • 分级：通常关键层（如首尾几层、敏感的注意力投影）保持 8 bit；其余 4 bit。
  • 显存收益：极致 — 权重平均位宽接近 5 bit。
  • 限制：与 FA3 量化互斥（详见特性兼容矩阵）。

W8A16 量化

仅权重量化为 int8，激活保持 fp16/bf16。

  • 优势：精度损失极小，几乎不需要离群值抑制。
  • 劣势：吞吐收益不如 W8A8，因为激活仍是高位宽。
  • 适用：对精度敏感的对话 / 推理类应用。

Attention 量化

把 Attention 中的 Q、K、V 统一量化为 8 bit。

  • 对 KV 的好处：KV Cache 立即压缩到 1/2，显存释放显著。
  • 对计算的好处：解码阶段 attention 矩阵乘可走 int8 算子。
  • 实现：依赖 ATB 中的 Attention 融合算子（ops/fla）。

FA3 量化

FA3（FlashAttention-3 风格）量化是 Attention 量化的精化版：

  • K 张量按是否经过 RoPE 分两段：非 RoPE 部分量化为 8 bit， RoPE 部分保留 fp16。
  • 这样既享受 KV 压缩的好处，又避免位置编码精度损失。
  • 典型搭配 DeepSeek 类长上下文模型。

KV Cache Int8

仅对 KV Cache 量化，不动权重 / 激活。

  • 显存收益：KV 占用 1/2，可承载更长上下文 / 更大 batch。
  • 吞吐影响：随显存释放，maxBatchSize 可调大，从而提吞吐。
  • 精度：KV 量化误差累积有限，但长 decode 链路下可观察。

W8A8SC 稀疏量化

SC = Sparse Compression。流程：

  1. 稀疏化：把绝对值最小的权重置零，按结构化或非结构化模式。
  2. 低位宽：剩余权重转 int8。
  3. 压缩存储：只存非零权重 + 索引，进一步减小磁盘 / 显存占用。
  • 价值：高稀疏率（典型 50–70%）+ 量化双重加速。
  • 限制：需要权重侧离线训练 / 校准；与 LoRA、Prefix Cache 等部分特性 存在兼容性约束。

W16A16SC 稀疏量化

另一种思路：仍保留 16 bit 浮点精度，但通过稀疏化 + 压缩存储降低 存储与带宽。

  • 不需要反量化算子，硬件友好。
  • 适合对精度极度敏感、又想从存储中要带宽的场景。

PD MIX 量化

Prefill / Decode 阶段对量化的敏感度不同：

  • Prefill：吞吐主导，激活量化收益大；可上 W8A8。
  • Decode：精度更敏感（每一步都受历史误差影响），可保留更高精度。

PD MIX 为 prefill 与 decode 独立选择量化方式，由调度层在 LayerwiseMixin 中切换 op 路径。

配置示例

各量化方式通过 ModelConfig.quantizationConfig（或权重侧的 quant_config.json）开启。例：

"ModelConfig": [{
  "modelName": "qwen2-7b-w8a8",
  "modelWeightPath": "/home/weight-w8a8",
  "worldSize": 4,
  "quantizationConfig": {
    "type": "w8a8",
    "antiOutlier": true,
    "kvCacheQuant": "int8"
  }
}]

权重目录里同时会有量化校准产物（scale / zero point）。如果用 W4A8 mix 或 W8A8SC，需要使用对应的离线量化工具生成专门的权重，不能 直接用 fp16 权重在线切换。

怎么选？

诉求推荐
精度优先（对话 / 评测）W8A16 + KV Int8
吞吐优先（高 QPS）W8A8 + 离群值抑制 + Attention 量化
极致压缩（小卡部署）W4A8 mix + KV Int8
长上下文 KV 瓶颈FA3 量化 + 序列并行
极致带宽（同卡跑更多模型）W8A8SC / W16A16SC
⚠ 评测先行

所有量化方案都会在不同程度上引入精度损失。上线前必须用业务真实数据集 做精度对比（参考 AISBench）。
