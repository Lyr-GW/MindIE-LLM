--- title: W8A8 量化 ---

W8A8 量化

把权重和激活统一量化成 INT8。是 LLM 量化最经典的方案 — 通过减小权重体积 + 走 INT8 矩阵乘，实现「显存降一半 + 吞吐升一档」。

这是什么

W8A8 = Weight 8-bit, Activation 8-bit。MatMul 算子吃 INT8 输入、吐 INT32 累加器， 最后反量化回 fp16/bf16。相比 fp16 矩阵乘，理论吞吐 ~2x。

数学原理

// 假设原 Linear: y = W · x + b           （W: fp16 [n,k]）
// W8A8 等效:    y = (Wq · scale_w) · (xq · scale_x - offset_x) + b
// 实际算子:     y = matmul_int8(xq, Wq) * deq_scale + quant_bias

input_scale, input_offset    : 把激活 x ∈ fp16 → xq ∈ int8 用
weight (Wq)                  : 离线已量化为 int8 的权重
quant_bias                   : 反量化时的整数偏置（含原 b 与零点修正项）
deq_scale                    : matmul 结果反量化到 fp16/bf16

权重布局

msModelSlim 量化后产物：

├─ config.json
├─ quant_model_description.json
└─ quant_model_weight_w8a8.safetensors
// quant_model_description.json
{
  "model.layers.0.self_attn.q_proj.weight":       "W8A8",
  "model.layers.0.self_attn.q_proj.input_scale":  "W8A8",
  "model.layers.0.self_attn.q_proj.input_offset": "W8A8",
  "model.layers.0.self_attn.q_proj.quant_bias":   "W8A8",
  "model.layers.0.self_attn.q_proj.deq_scale":    "W8A8"
}

张量 dtype / shape 一览（原始 fp16，shape [n, k]）：

张量weightinput_scaleinput_offsetquant_biasdeq_scale
dtypeint8fp16fp16int32int64
shape[n,k][1][1][n][n]

对 bf16 原权重，input_scale/offset 为 bf16，deq_scale 为 fp32。

推理时算子流程

   x (fp16/bf16)
       │   ─ * 1/input_scale + input_offset → round → int8
       ▼
   xq (int8) ─┐
              ├─ matmul_int8 ─ acc(int32) ─ * deq_scale → fp16
   Wq (int8) ─┘                               + quant_bias
                                                   │
                                                   ▼
                                                   y

如何开启

核心步骤：用 msModelSlim 把浮点权重量化为 W8A8 → 直接把 modelWeightPath 指向量化后的目录即可。

# 1. 生成量化权重（以 Qwen2-7B 为例）
msmodelslim quant \
  --model_path /home/Qwen2-7B \
  --save_path  /home/Qwen2-7B-W8A8 \
  --device     npu \
  --model_type Qwen2-7B \
  --quant_type w8a8 \
  --trust_remote_code True
// config.json
"ModelConfig": [{
  "modelName":         "qwen2-7b-w8a8",
  "modelWeightPath":   "/home/Qwen2-7B-W8A8",
  "worldSize":         4,
  "trustRemoteCode":   false
}]

收益（典型）

  • 权重体积 ≈ 1/2，maxBatchSize 可上调一档。
  • 单步 decode 时延降低 20–35%（受卡间通信占比影响）。
  • 精度损失：在搭配 Anti-Outlier 后，常用 benchmark 损失 0.5–1 pp。

兼容性

  • 需要原模型有对应的 W8A8 量化权重；不能用 fp16 权重在线开启。
  • 与 KV Cache Int8、Attention 量化、 Prefix Cache 兼容。
  • 与 Multi-LoRA 当前版本不兼容（详见 兼容矩阵）。

调优建议

  • 开启 W8A8 后，调大 maxBatchSize 直到显存即将打满，吞吐提升通常显著。
  • 若精度不达预期，先排查是否使用了带 Anti-Outlier 的版本；再考虑 PDMIX 量化（P 阶段 per-token）。
  • 评估时使用业务真实分布的数据集，不要只看 perplexity。

常见问题

  • 启动报错 dtype 不匹配？检查 quant_model_description.json 是否与权重 safetensors 配套。
  • 性能不升反降？极小模型（< 1B）做 W8A8 收益有限；矩阵规模太小时反量化开销占比大。
  • 反量化后输出有 NaN？大概率是 scale 计算溢出，重新校准并加入 outlier clamp。
