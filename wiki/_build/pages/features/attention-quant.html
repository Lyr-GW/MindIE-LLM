--- title: Attention 量化 ---

Attention 量化

把注意力中的 Q / K / V 三个张量统一量化为 INT8。 KV Cache 显存压一半，decode 阶段 attention 算子加速，吞吐显著提升。

为什么单独做 Attention 量化

常规 W8A8 只覆盖 Linear 层，但 attention 内部的 Q·K^T 与 softmax(...)·V 两次大矩阵乘 仍是 fp16，且 KV Cache 占了 decode 阶段绝大部分显存。把 QKV 都量到 8 bit：

  1. KV Cache 显存立刻降一半 → maxBatchSize 可调大；
  2. attention 矩阵乘走 INT8 算子 → 算力翻倍；
  3. 预计 decode 吞吐有 30–50% 提升。

权重描述

{
  "model_quant_type": "W8A8",
  "fa_quant_type":    "FAQuant",       // ← 标志 attention 量化已启用
  "model.layers.0.self_attn.q_proj.weight":       "W8A8",
  "model.layers.0.self_attn.q_proj.input_scale":  "W8A8",
  "model.layers.0.self_attn.q_proj.deq_scale":    "W8A8",
  "model.layers.0.self_attn.k_proj.weight":       "W8A8",
  "model.layers.0.self_attn.v_proj.weight":       "W8A8",
  "model.layers.0.self_attn.o_proj.weight":       "W8A8"
}

scale / offset 张量布局（per-head 量化）：

张量dtypeshape
q_scale / q_offsetfp16[q_head_num, head_dim]
k_scale / k_offsetfp16[kv_head_num, head_dim]
v_scale / v_offsetfp16[kv_head_num, head_dim]

注意：scale 是 per-head + per-channel，粒度比 Linear 量化更细，因为 attention 头之间的 尺度差异显著。

推理数据流

   x ─→ q_proj(W8A8) ─→ q (fp16) ──── * 1/q_scale + q_offset ──→ q (int8)
                             ┐
   x ─→ k_proj(W8A8) ─→ k (fp16) ──── * 1/k_scale + k_offset ──→ k (int8)
                             ├──→ Paged Attention (int8) ─→ acc(int32) ─→ * deq → fp16 ─→ out
   x ─→ v_proj(W8A8) ─→ v (fp16) ──── * 1/v_scale + v_offset ──→ v (int8)
                             │
   KV Cache 池存储 ─────────int8 (体积压 2x)

如何开启

需要使用包含 Attention 量化（FAQuant）的权重。当前主要在 LLaMA3.1-70B 上验证：

msmodelslim quant \
  --model_path /home/llama3.1-70b \
  --save_path  /home/llama3.1-70b-w8a8-fa \
  --device     npu \
  --model_type LLaMA3.1-70B \
  --quant_type w8a8 \
  --fa_quant   \
  --trust_remote_code True

启动服务时，quant_model_description.json 中的 "fa_quant_type": "FAQuant" 字段 会被自动识别，无需额外开关。

已知限制

  • 仅 Atlas 800I A2 推理服务器支持。
  • 仅支持 LLaMA3.1-70B（其它模型陆续支持）。
  • 必须与 W8A8 一同使用。
  • 仅支持 fp16；与长序列特性、 Function Call 协同。

Attention 量化 vs FA3 量化

Attention 量化FA3 量化
K 张量整体 int8非 RoPE 部分 int8、RoPE 部分保留 fp16
典型模型LLaMADeepSeek（用 MLA + RoPE）
动机普通注意力避免 RoPE 量化精度坍塌
