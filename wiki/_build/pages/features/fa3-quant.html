--- title: FA3 量化 ---

FA3 量化（FlashAttention-3 风格）

在 Attention 量化 基础上做了一项关键改动： K 的非 RoPE 张量量化为 INT8、K 的 RoPE 张量保留 fp16。专为 DeepSeek-MLA 这类对位置编码极敏感的模型设计。

为什么 RoPE 不能量化

DeepSeek 使用 MLA（Multi-head Latent Attention）+ RoPE 位置编码。MLA 把 K 分成两段：

  • k_nope：内容部分，分布平稳、易量化。
  • k_pe：经过 RoPE 旋转后的部分，每个位置对应一组 sinusoidal 振幅， 最大值随上下文位置漂移大，且不同 token 之间差异显著 — 量化误差会被注意力放大。

所以 FA3 量化的策略是：k_nope → int8、k_pe → 保 fp16。

权重描述

{
  "model_quant_type": "W8A8_DYNAMIC",
  "fa_quant_type":    "FAKQuant",          // ← 区别于普通 FAQuant
  "model.layers.0.self_attn.q_proj.weight":       "W8A8",
  "model.layers.0.self_attn.q_proj.input_scale":  "W8A8",
  "model.layers.0.self_attn.k_proj.weight":       "W8A8",
  "model.layers.0.self_attn.v_proj.weight":       "W8A8",
  "model.layers.0.self_attn.o_proj.weight":       "W8A8"
}

per-head scale 张量布局：

张量dtypeshape
q_scale / q_offsetfp16[q_head_num, head_dim]
k_scale / k_offsetfp16[kv_head_num, head_dim]

数据流

   k_proj 输出 = [k_nope (大头) | k_pe (RoPE 部分)]
                       │              │
                  量化为 int8     保留 fp16
                       │              │
                       └─── concat ───┘ → 写入 KV Cache (混合精度)

   注意力计算：
   q @ k_nope^T  → int8 算子（高速）
   q @ k_pe^T    → fp16 算子（保精度）
   再 softmax 并加权 V

必须开启 KV Cache NZ 格式

FA3 量化要求 KV 在显存中以 NZ（昇腾专用对齐格式）布局存储以匹配算子吃数方式。

"ModelConfig": [{
  "modelName": "deepseekr1",
  "modelWeightPath": "/weights/R1_W8A8_FA3",
  "worldSize": 8,
  "models": {
    "deepseekv2": {
      "kv_cache_options": { "enable_nz": true }
    }
  }
}]

PD 分离场景下两端都要开启。

生成权重

cd msmodelslim/example/DeepSeek/
python3 quant_deepseek_w8a8.py \
  --model_path /weights/DeepSeek-R1 \
  --save_path  /weights/DeepSeek-R1-W8A8-FA3 \
  --batch_size 4 \
  --fa_quant   \
  --mindie_format
# 检查 quant_model_description.json 应包含 "fa_quant_type": "FAKQuant"

已知限制

  • Atlas 800I A2 / A3 支持。
  • 仅支持 DeepSeek-R1、DeepSeek-V3、DeepSeek-R1-0528。
  • 仅支持 fp16，且必须开 NZ 格式。
  • 与 W4A8 混合量化互斥（详见 兼容矩阵）。

收益

  • DeepSeek-R1 长上下文场景，KV 显存压一半，128k 也能跑得动。
  • decode 吞吐 +30–45%。
  • 精度损失通常 < 1 pp（vs 纯 W8A8）。
