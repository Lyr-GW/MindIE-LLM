W8A16 量化

仅把权重量化为 INT8，激活保持 FP16/BF16。 在精度损失最小的前提下显著降低权重体积，是「精度优先」量化方案的代表。

什么时候选 W8A16

  • 对评测精度极敏感（对话、考试题、医疗 / 法律等）。
  • 显存压力主要来自权重而不是 KV Cache。
  • 部署平台只支持 W8A16（如 Atlas 800I A2 推理服务器）。

原理

逐通道（per-channel）对权重 W ∈ fp16 [n,k] 做对称量化，得到：

weight        : int8     shape [n,k]
weight_scale  : fp32     shape [n,1]
weight_offset : fp32     shape [n,1]      // 一般为 0（对称）

y = (Wq * weight_scale + weight_offset) · x  + b

由于激活是浮点，没有激活量化的精度损失；仅有权重量化误差，per-channel 粒度也能很好抑制。

权重布局

├─ config.json
├─ quant_model_description.json
└─ quant_model_weight_w8a16.safetensors
// quant_model_description.json
{
  "model_quant_type": "W8A16",
  "model.embed_tokens.weight": "FLOAT",
  "model.layers.0.self_attn.q_proj.weight":        "W8A16",
  "model.layers.0.self_attn.q_proj.weight_scale":  "W8A16",
  "model.layers.0.self_attn.q_proj.weight_offset": "W8A16"
}

张量 shape / dtype（原 fp16）：

张量weightweight_scaleweight_offsetbias
dtypeint8fp32fp32fp16
shape[n,k][n,1][n,1][n]

推理时数据流

   Wq (int8)──┬─ * weight_scale + weight_offset ──→ W' (fp16) ─┐
                                                              ├─ matmul_fp16 ─→ y
                                       x (fp16) ───────────────┘

由于 matmul 仍是 fp16，单步算力不会超 fp16 baseline；收益主要在权重读取 带宽：从 fp16 16 bit/参数 降到 8 bit/参数。

如何开启

# 生成量化权重
msmodelslim quant \
  --model_path /home/Qwen2-72B \
  --save_path  /home/Qwen2-72B-W8A16 \
  --device     npu \
  --model_type Qwen2-72B \
  --quant_type w8a16 \
  --trust_remote_code True
"ModelConfig": [{
  "modelName": "qwen2-72b-w8a16",
  "modelWeightPath": "/home/Qwen2-72B-W8A16",
  "worldSize": 8
}]

收益

  • 权重体积 ≈ 1/2，70B 模型可在 4 卡装下（fp16 通常 8 卡）。
  • 带宽节省让 decode 阶段（访存瓶颈）速度提升 15–30%。
  • 精度损失通常 < 0.3 pp（CMMLU/MMLU 等）。

已知限制

  • 仅 Atlas 800I A2 推理服务器支持。
  • 仅支持 LLaMA3-70B、Qwen1.5-110B、Qwen2-72B 等部分大模型。
  • 仅支持与 Anti-Outlier、 KV Cache Int8 配合。
  • 与 Multi-LoRA 不兼容（同 W8A8）。
  • 仅当原 Linear 有 bias 时，量化权重才会有 bias。

W8A16 vs W8A8 选型

维度W8A16W8A8
权重体积≈ 1/2≈ 1/2
单步算力= fp16≈ 2× fp16
精度损失< 0.3 pp0.5–1 pp（带 Anti-Outlier）
