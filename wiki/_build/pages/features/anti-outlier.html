离群值抑制（Anti-Outlier）

在做激活量化前，把激活分布里少数「极端值」抑制下去，让大多数正常数值 不被它们「绑架」掉精度。是几乎所有 W8A8 / W4A8 量化的前置预处理。

这是什么 / 解决什么问题

对张量做 INT8 量化，本质是把 fp16 的实数范围映射到 [-128, 127]：

scale = max(|x|) / 127
x_q   = round(x / scale)

问题：如果 99% 的激活在 [-2, 2] 而 1% 在 [-50, 50]，scale 会被推到约 0.4， 正常值的有效精度只剩 5–6 个量化等级，模型精度大幅下降。

这就是 LLM 推理量化的著名痛点 — 激活里的「outliers」。 SmoothQuant 风格的离群值抑制方案给出经典解法：把激活的难量化 部分等效迁移到权重上。

工作原理

对一个 Linear 层 y = W · x，引入按通道缩放因子 s：

y = W · x
  = (W · diag(s)) · (diag(s)⁻¹ · x)
  = W'   ·   x'
其中  W' = W · diag(s)
      x' = x / s

把激活的极端通道按 s 缩小（变得「平」）→ 激活更易量化； 代价是权重相应「胖」一点 → 权重量化稍难。 s 通过校准数据离线确定，目标是让两侧量化总误差最小。

在 MindIE-LLM 中的实现位置

  • 权重侧：由 msModelSlim 离线工具生成， 在 quant_model_description.json 中以 "input_layernorm.bias" / "post_attention_layernorm.bias" 等额外 bias 形式承载。
  • 推理侧：由 ATB Models 的量化 Linear 算子接收上述 bias，按以下逻辑展开：
    1. Norm 层引入：在 RMSNorm 输出上加 norm_bias（让激活分布回归原始等价）。
    2. Linear 层抵消：紧随其后的 Linear 层减去对应 norm_bias。
    3. Per-tensor 场景：直接融合进 quant_bias，免一次额外加法；
    4. Per-token 场景：作为 Linear 的浮点 bias 单独存在。

权重描述（关键字段）

// quant_model_description.json 节选（W8A8 + Anti-Outlier + PDMIX）
{
  "model.layers.0.self_attn.q_proj.weight": "W8A8_MIX",
  "model.layers.0.self_attn.q_proj.bias": "FLOAT",            // optional, per-token 时才有
  "model.layers.0.self_attn.q_proj.quant_bias": "W8A8_MIX",   // per-tensor 时融入这里
  "model.layers.0.self_attn.q_proj.input_scale": "W8A8_MIX",
  ...
  "model.layers.0.input_layernorm.weight": "FLOAT",
  "model.layers.0.input_layernorm.bias":   "FLOAT",           // ← anti-outlier 引入
  "model.layers.0.post_attention_layernorm.weight": "FLOAT",
  "model.layers.0.post_attention_layernorm.bias": "FLOAT"     // ← anti-outlier 引入
}

如何开启

用户侧基本「自动」 — 只要使用了 msModelSlim 默认参数生成的 W8A8 / W4A8 / W8A8C8 量化权重， 就已经包含离群值抑制。生成命令：

msmodelslim quant \
  --model_path {浮点权重路径} \
  --save_path  {量化权重路径} \
  --device     npu \
  --model_type Qwen3-14B \
  --quant_type w8a8 \
  --trust_remote_code True

收益

  • 典型场景下 W8A8 + Anti-Outlier vs 纯 W8A8：CMMLU / MMLU 精度损失从 2–4 pp 降到 0.5–1 pp。
  • 不增加推理算力 — 所有「迁移」在权重侧已完成。
  • 对带 RMSNorm 的主流模型（LLaMA / Qwen / DeepSeek）都适用。

已知限制

  • 仅作用于激活量化场景；纯权重量化（如 W8A16）不需要。
  • 非对称模式会引入额外 bias，per-token 场景多一次 Add。 PDMIX 的 P 阶段（per-token）若对该精度增益不敏感，可考虑去掉 bias 提升性能。

常见问题

  • 权重比浮点大了？多了一些 fp32 / fp16 bias 张量， 相对模型本体可忽略。
  • 不同模型的 bias 数量不一致？取决于原模型有无 bias — Qwen2 系列原本就有 bias，会直接融合；Qwen3-32B 无 bias，会新建 bias 层。
  • 能与 KV Cache Int8 共用吗？可以，已是常见组合。
