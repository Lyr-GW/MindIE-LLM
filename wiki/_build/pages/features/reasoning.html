--- title: 思考解析与思考预算 ---

思考解析（Reasoning）+ 思考预算 + 思考流

面向「推理增强型模型」（DeepSeek-R1 / Qwen-QwQ / Qwen3 reasoning）： 思考解析 把 reasoning 段从最终答案中拆出来；思考预算 限制 reasoning token 数量；思考流 让流式接口分轨推送两段。

思考解析（Reasoning）

推理增强型模型生成内容时常包含「内心独白」段，例如：

<think>
让我想想：1+1=2，所以...
</think>
答案是 2。

「思考解析」把它拆成两个字段：

  • reasoning_content：模型推理 / 分析 / 逻辑判断的过程；
  • content：最终回答。

配置

"ModelConfig": [{
  "modelName": "Qwen3-32B",
  "models": {
    "qwen3": { "enable_reasoning": true }
  }
}]

注意 "qwen3" 字段需根据模型替换：

  • Qwen3-30B-A3B → qwen3_moe
  • DeepSeek-R1 → deepseekv2 且权重 config.json 中 model_type 改为 deepseek_v3
  • DeepSeek-V3.2 → deepseek_v32

DeepSeek-V3.1 的开关

DeepSeek-V3.1 需在请求中传 "chat_template_kwargs": {"enable_thinking": true}， 或在 tokenizer_config.json 中加同名字段。

思考预算（thinking_budget）

限制 reasoning 段的 token 数；超过预算时引擎自动注入结束思考提示词截断思考， 促使模型直答。

配置

"models": {
  "qwen3": {
    "early_stopping_text": "\n\nConsidering the limited time by the user, \
I have to give the solution based on the thinking directly now.\n</think>\n\n"
  }
}

请求时传入预算：

{
  "model": "Qwen3-32B",
  "messages": [...],
  "chat_template_kwargs": { "thinking_budget": 512 }
}

注意

  • 预算过小时，输出可能切换到与提示词语言一致（典型英文）。
  • 不支持与 use_beam_search 等多序列后处理同开。

思考流（Thinking Stream）

流式接口下，reasoning 段与 content 段可分轨推送：客户端可以同时收到 「思考流」与「最终回答流」，UI 上展示进度的同时，最终结果的字段单独存在。 具体协议字段以 reasoning_content + content 的逐 token 增量返回。

在 Python 框架中的实现

对应 ATB Models 中的 chat_template 渲染 + Python 后处理插件。引擎按 <think>...</think> 标签分拆，并向上层 endpoint 暴露两个字段。

已知限制

  • Atlas 800I A2 / A3、Atlas 300I Duo 支持。
  • 支持模型：Qwen3-32B、Qwen3-235B-A22B、Qwen3-30B-A3B、DeepSeek-R1、DeepSeek-V3.1。
  • 仅支持 OpenAI 推理接口。
  • DeepSeek-V3.1 的 Function Call 与思考解析不能同请求开启。
