目录结构

本章按「顶层 → src/ 子模块 → mindie_llm/ 子模块」 三个层次解读仓库布局，帮助你快速定位想读的代码。

顶层目录

MindIE-LLM/
├── mindie_llm/         # Python 推理框架主模块
├── src/                # C++ 引擎核心
├── proto/              # gRPC / 进程间通信 protobuf
├── examples/           # 示例代码（含 atb_models 后端）
├── docs/               # 官方 mkdocs 中文文档
├── scripts/            # 构建 / 部署 / 打包脚本
├── tools/              # 辅助工具与示例
├── tests/              # 单元 / 集成 / 模糊测试
├── cmake/              # CMake 模块（FindXxx.cmake 等）
├── pre-commit/         # pre-commit hook 脚本
├── third_party_entry/  # 第三方依赖入口（占位）
├── requirements/       # 各场景 Python 依赖
├── CMakeLists.txt      # 根 CMake 配置
├── build.sh            # 一键构建入口
├── setup.py / setup_mindie_llm.py / pyproject.toml
├── README.md / contributing.md / security.md / LICENSE.md
└── mkdocs.yml          # mkdocs 文档配置
目录主要内容说明
mindie_llm/Python 包源码 对外发布的 mindie_llm wheel 主体
src/C++ 引擎 编译产出 libllm_*.so 与 mindie_llm_server
proto/model_execute_data.proto 主进程 ↔ worker 间的执行结果协议
examples/atb_models/ATB 模型后端 含 atb_framework / atb_llm 适配层
docs/zh/mkdocs 文档源 用户 / 开发指南 / FAQ / 架构图
scripts/构建脚本 详见 安装与编译
tools/辅助工具 llm_manager_python_api_demo 旧 Python API 示例
tests/测试用例 含 dlt、fuzztest_llmmanager、pythontest
cmake/CMake 模块 查找 CANN / ATB / Python / gRPC 等
pre-commit/钩子脚本 配合 .pre-commit-config.yaml 做代码检查
third_party_entry/第三方占位 实际依赖在构建脚本中拉取或对接系统包
requirements/分场景依赖 测试 / 文档 / 运行依赖分文件维护
style.cfg / .clang-format代码风格 C++ 与 Python 通用风格定义
config.conf占位配置 仅 42 字节，含构建期默认配置项

核心子目录速查

子目录关键文件职责
engine/ llm_engine.cpp/h、scheduler_config.cpp、 buffered_responser.h、seq_group_builder_from_infer_req.*、 construct_execute_request.*、model_exec_output_handler.*、 transfer_output_handler.*、lora_manager.*、 layerwise_mixin.cpp、loraops_mixin.cpp 把上层的 InferRequest 串成 SequenceGroup、组 batch、回写 token。详见 C++ 引擎内核。
scheduler/ scheduler.cpp/h、pre_scheduler.*、post_scheduler.*、 policy/（fcfs_policy、pdds_policy、 layerwise_fcfs_policy、stage_policy、 policy_factory、policy_helper、 seq_group_collection、dynamic_batch_size）， latency_predictor/ 请求入队 / 等待 / 出队的调度大脑。
block_manager/ self_attn_block_manager.*、lwd_self_attn_block_manager.*、 hashless_block_allocator.*、prefix_cache_block_allocator.*、 cpu_npu_block_allocator.*、device_aware_block_allocator.h、 lru_evictor.*、copy_on_write_tracker.*、 ref_counter.*、hit_rate_calculator.*、 block_table.*、block_tracker.*、obj_pool.h PagedAttention / Prefix Cache / KV 池化的全部实现。
llm_manager/ llm_manager.cpp、llm_manager_adapter.*、 infer_request_impl.cpp、llm_infer_request.cpp、 llm_infer_response.cpp、infer_tensor.cpp、 python_api/ 对外 C++ / Python API；新代码请用 llm_manager_v2/ 提供的接口。
server/ daemon/llm_daemon.cpp、endpoint/（含 http_wrapper、grpc_wrapper、health_checker、 single_llm_req_handler、single_req_infer_interface、 endpoint_def.*、endpoint.cpp、utils）， conf/、scripts/、tokenizer/、 infer_instances/、include/、options.cmake 对外协议层 + 守护进程入口。
executor/ executor.*、communicator.*、 grpc_communicator.*、ipc_communicator.* 主进程 ↔ worker 通信抽象（gRPC / IPC 双形态）。
sequence/ sequence.cpp、sequence_group.cpp、 live_infer_context.cpp、scheduling_budget.cpp 请求 / 序列 / 上下文 / 调度预算建模。
config_manager/ base_config_manager.h、config_manager_impl.*、 server_config.cpp、backend_config.cpp、 schedule_config.cpp、model_deploy_config.cpp、 ranktable_config.cpp、config_dynamic_handler.cpp、 config_interaction.*、param_checker.cpp 解析与校验所有配置；支持运行时动态修改。
load_balance/ load_balancer.*、balance_policy/ 多 worker 实例的请求分发策略。
llm_manager_v2/ 下一代 Manager，承担更现代的 API（与新 Python 框架对齐） 逐步替换旧 llm_manager/
kernels/ 自定义算子 / kernel 实现 构建脚本 scripts/build_kernels.sh
py_interface/ Python 与 C++ 之间的数据 / 张量互转 通常被 llm_manager/python_api 调用
utils/ 日志 / 共享内存 / 加密 / id 生成 / 字符串等基础工具 无业务依赖
include/ 对外公开头文件 第三方集成时只需依赖此目录

Python 框架：mindie_llm/

mindie_llm/
├── connector/          # 请求接入层
├── text_generator/     # 推理工作流（含 plugins）
├── modeling/           # 模型抽象
├── runtime/            # 运行时（layers、ops、tokenizer、lora、…）
├── distributed/        # 分布式通信封装
├── server/             # 入口脚本（main.py）
├── tokenizer/          # 自研 / 包装 tokenizer
├── model_wrapper/      # 模型包装器
├── examples/           # 示例代码
└── utils/              # 工具（logger、tensor_utils、validator…）
子目录关键内容说明
connector/ main.py、request_listener/、request_router/、 cpp/、common/ 从 C++ Server 拿到请求后，路由到具体的 Python text_generator 实例。
text_generator/ generator.py、adapter/、samplers/、 mempool/、plugins/、cpp/、utils/ 核心自回归循环；插件机制实现 Prefix Cache、SplitFuse、MTP、LA、 Memory Decoding、Structured Output 等。
modeling/ backend_type.py、model_wrapper/atb/ 定义后端类型，对接 ATB Models / ACLGraph。
runtime/ model_runner/、models/、compilation/、 tokenizer/、config/、conf/、lora/、 utils/、layers/、ops/ 真正调用昇腾算子的运行时。详见 Python 推理框架。
distributed/ 分布式通信封装 处理 TP / DP / EP 各组通信组管理。
server/main.py 独立 Python 服务入口 用于无 C++ daemon 的轻量调试场景。
tokenizer/ 词表与分词器封装 支持 fast tokenizer 加速。
model_wrapper/ 模型包装层 把开源模型包装成统一 forward 接口。
examples/ Python 调用示例 调试、二次开发参考。
utils/ 日志 / 张量 / Profiling / 校验 所有 Python 模块共享。

Text Generator 内置插件

路径：mindie_llm/text_generator/plugins/

  • prefix_cache — Prefix Cache 命中复用
  • splitfuse — 长 Prefill 切块调度
  • memory_decoding — 基于历史 KV 的快速解码
  • la — Lookahead Decoding
  • mtp — Multi-Token Prediction
  • structured_output — JSON / 正则约束输出
  • layer_skipped — 跳层推理
  • plugin_manager.py / plugin_manager_lwd.py / plugin.py — 插件生命周期管理

示例与工具

  • examples/atb_models/atb_framework — ATB 推理框架包装。
  • examples/atb_models/atb_llm — ATB LLM 模型适配层。
  • tools/llm_manager_python_api_demo — 旧版 Python API 调用示例。
  • tools/setup.py — 工具自身的安装入口。

测试目录

  • tests/dlt — 数据 / 张量层 C++ 单测。
  • tests/fuzztest_llmmanager — 针对 LLM Manager 的模糊测试。
  • tests/pythontest — Python 端单测 / 集成测试。
  • tests/run_all_tests.sh — 一键跑全部测试。
  • tests/requirements.txt — 测试专用依赖。

文档结构

docs/zh/ 是官方 mkdocs 中文文档，主要分类：

  • user_guide/ — 安装 / 快速入门 / 使用手册 / 模型支持列表 / 特性。
  • developer_guide/ — 架构设计 / 编译指南 / 迁移与适配。
  • faq/ — 常见问题。
  • release_notes.md — 版本说明。

本 Wiki 与 mkdocs 文档不冲突：mkdocs 文档面向终端用户的官方说明， Wiki 则按主题对源码进行二次归纳。
