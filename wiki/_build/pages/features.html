特性总览

MindIE-LLM 的特性按用途分为六大类：基础并行 / 量化 / 长序列 / 调度 / 加速 / 交互，再加一项「其他」。本章给出全景索引与兼容矩阵；具体细节 参见专题章节：量化、 并行、加速。

⚠ Multi-LoRA 与量化互斥

当前 Qwen 模型上 Multi-LoRA 与多数量化特性（W8A8 / W8A16 / KV Int8 / W8A8SC 等）不兼容。 生产部署需在「多业务热切」与「极致压缩」之间二选一。

特性如何启用

大部分特性通过 config.json → ModelConfig.pluginParams 中的开关启用， 例如：

"pluginParams": {
  "prefix_cache": { "enable": true, "blockSize": 16 },
  "split_fuse":   { "enable": true, "chunkTokens": 1024 },
  "mtp":          { "enable": false, "kStep": 2 },
  "kv_pool":      { "enable": false, "cpuMemSize": 16 }
}

个别特性还需要环境变量与权重侧支持（例如某些量化方案要求专门的量化权重）。
