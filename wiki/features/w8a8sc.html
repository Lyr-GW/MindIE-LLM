W8A8SC 稀疏量化

三步合一：稀疏化 + 8-bit 量化 + 压缩存储。 面向 Atlas 300I Duo 推理卡，最大化降低权重体积，把更多模型塞进同一张卡。

三步流程

   原 fp16 权重
        │
        ▼  ① 稀疏（msModelSlim）
   W8A8S：少数权重置零，剩余值仍为 fp16
        │
        ▼  ② INT8 量化
   仍为 [n,k] int8，部分位置为 0
        │
        ▼  ③ 压缩
   W8A8SC：只保存非零元素 + 索引（index）+ 压缩信息（info）

为什么稀疏 + 量化 + 压缩

  • 仅量化（W8A8）：权重压到 1/2。
  • 仅稀疏：物理存储不变，只是大量 0；不压缩则带宽收益为 0。
  • 稀疏 + 压缩：把 0 完全省去，权重体积可降至 1/3 ~ 1/4。
  • 再叠 INT8 量化：极限可降至 1/6 以下。

权重布局

压缩后权重按 TP 数分多份目录：

├─ part0-of-4
│  ├─ quant_model_weight_w8a8sc.safetensors
│  └─ quant_model_description.json
├─ part1-of-4 / ... / part3-of-4
└─ tokenizer*
// part0-of-4/quant_model_description.json
{
  "model_quant_type": "W8A8SC",
  "transformer.h.0.attn.c_attn.weight": "W8A8SC",   // 非零值（int8）
  "transformer.h.0.attn.c_attn.index":  "W8A8SC",   // 非零位置索引
  "transformer.h.0.attn.c_attn.info":   "W8A8SC",   // 压缩参数
  "transformer.h.0.attn.c_attn.input_scale":  "W8A8S",
  "transformer.h.0.attn.c_attn.input_offset": "W8A8S",
  "transformer.h.0.attn.c_attn.deq_scale":    "W8A8S",
  "transformer.h.0.attn.c_attn.quant_bias":   "W8A8S"
}

关键张量：

张量weightindexinput_scalequant_biasdeq_scale
dtypeint8int8fp16int32int64
shape[x] (x ∈ (0, n×k])[y]（解码索引）[1][n][n]

y 由稀疏 tile 大小决定，详见官方 md。

如何开启

# 1. 量化为 W8A8S（仍未压缩）
msmodelslim quant \
  --model_path /home/Qwen3-8B \
  --save_path  /home/Qwen3-8B-W8A8S \
  --device     npu \
  --model_type Qwen3-8B \
  --quant_type w8a8s \
  --trust_remote_code True

# 2. 切分 + 压缩
torchrun --nproc_per_node 4 \
  -m examples.convert.model_slim.sparse_compressor \
  --model_path /home/Qwen3-8B-W8A8S \
  --save_directory /home/Qwen3-8B-W8A8SC

# 3. 启动推理（每张卡读对应 partN-of-4）
cd ${ATB_SPEED_HOME_PATH}
bash examples/models/qwen/run_pa.sh -m /home/Qwen3-8B-W8A8SC --trust_remote_code true

已知限制

  • 压缩算法和硬件强相关，仅 Atlas 300I Duo 推理卡支持。
  • 不支持 bfloat16 权重。
  • 仅支持 Qwen3-8B、Qwen3-14B、Qwen3-32B。
  • 仅与 并行解码、Prefix Cache、 Function Call、长序列特性同时使用。

收益

  • 典型稀疏率 50–70%；权重体积可低至 fp16 的 1/4。
  • matmul 走稀疏算子，吞吐提升 1.3–1.6×。
  • 需要业务侧评估精度损失（多 1–2 pp）。
