MindIE-LLM 是什么

MindIE-LLM（Mind Inference Engine for Large Language Models）是华为 昇腾推理生态中专注于大语言模型推理加速的核心组件。它把昇腾硬件 （Atlas 800I A2 / A3 等）的算力潜能与业界主流的 LLM 服务化协议串联起来，提供 高吞吐、低时延、低显存的端到端推理能力。

从外部接口看，它兼容 OpenAI / Triton / TGI / vLLM 四大主流协议； 从内部实现看，它以 C++ 引擎驱动调度与 KV Cache 管理，以 Python 框架承担模型加载、 算子编排、采样后处理与高级特性插件，并以 ATBGraph / ACLGraph 双图模式后端 榨取昇腾算子的极限性能。

五大核心能力

高吞吐
服务化推理
Continuous Batching + PagedAttention 默认开启， 配合 SplitFuse、异步调度、并行解码等策略，撑起千并发级在线服务。
低显存
高效 KV 管理
分块式 Block Manager + LRU 驱逐 + Copy-on-Write + Prefix Cache + KV Cache 池化，把宝贵的 NPU 显存利用到极致。
低精度
丰富量化矩阵
W8A8 / W8A16 / W4A8 混合 / W8A8SC 稀疏 / KV Cache Int8 / Attention / FA3 …… 在精度与性能间灵活取舍。
大模型
多维并行
张量并行 (TP)、数据并行 (DP)、专家并行 (EP)、 上下文并行 (CP)、序列并行 (SP)，支持万亿参数 MoE 与 128k 长上下文。
混部
PD 分离 & 池化
Prefill / Decode 实例混合部署，KV Cache 跨实例 传输与 DRAM/SSD 池化，提升集群整体利用率。
