W4A8 混合量化

对模型不同层级采用不同位宽：路由专家层走 W4A8（4-bit 权重 + 8-bit 激活），关键层保留 W8A8。是 DeepSeek-R1 / V3 类 MoE 模型在昇腾上跑出极致密度的 看家方案。

为什么需要混合

DeepSeek-V3 / R1 这类巨型 MoE 模型有 600B+ 参数，即使做 W8A8 权重也需要 600+ GB — Atlas 800I A3 单节点装下也很紧张。把路由专家（占总参数 ~90%）压到 4 bit，整体权重再降一半， 但同时要避免「敏感」层精度坍塌。

分层策略（DeepSeek-R1/V3）

   层 0 ──────── MLP                       W8A8 Dynamic   （per-token，精度优先）
   层 1 ──────── MLP                       W8A8 Dynamic
   层 2 ──────── MLP                       W8A8 Dynamic
   层 3..N ───── MLA + 共享专家             W8A8           （per-tensor，性能优先）
                 路由专家 (experts.0..k)   W4A8 Dynamic   （Per-channel + Per-group 4-bit）
  • 前 3 层 MLP：模型对齐与对话风格的核心，per-token 量化保精度。
  • MLA + 共享专家：每个 token 都过，访存敏感，per-tensor 提性能。
  • 路由专家：稀疏调用，总参数量大；4 bit 是 token-级误差容忍度内的最优解。

权重描述（节选）

{
  "model_quant_type": "W8A8_DYNAMIC",
  "model.layers.0.self_attn.q_proj.weight":        "W8A8",
  "model.layers.1.mlp.gate_proj.weight":           "W8A8_DYNAMIC",
  "model.layers.3.mlp.experts.0.gate_proj.weight": "W4A8_DYNAMIC",
  "model.layers.3.mlp.experts.0.gate_proj.weight_scale":         "W4A8_DYNAMIC",
  "model.layers.3.mlp.experts.0.gate_proj.weight_scale_second":  "W4A8_DYNAMIC",
  "model.layers.3.mlp.experts.0.gate_proj.scale_bias":           "W4A8_DYNAMIC"
}

4-bit 量化为双级：

  • weight：int4，每个 fp16 数被压到 4 bit。
  • weight_scale：per-channel scale（粗粒度，shape [n,1]）。
  • weight_scale_second：per-group scale（细粒度，shape [n,group_num]）， 在 channel 内再分组校准。
  • scale_bias：uint64 偏置，用于反量化整数路径。

为什么 4-bit 需要双 scale

4 bit 只有 16 个量化等级，全 channel 共享 scale 时极易被 channel 内某些大值挤压。 划分 group（如每 64 个权重一组）共享 fine-grained scale，能让分布差异大的子集 各取所需，是 AWQ / GPTQ 的常见做法。代价是 scale 占用更多空间，但相对 4-bit 主体仍可忽略。

如何开启

# DeepSeek-V3/R1 W4A8 量化（msModelSlim 提供专用脚本）
cd msmodelslim/example/DeepSeek/
python3 quant_deepseek_w4a8.py \
  --model_path /weights/DeepSeek-R1 \
  --save_path  /weights/DeepSeek-R1-W4A8 \
  --batch_size 4 \
  --mindie_format
"ModelConfig": [{
  "modelName":       "deepseek-r1-w4a8",
  "modelWeightPath": "/weights/DeepSeek-R1-W4A8",
  "worldSize":       16,
  "tp": 8, "moe_ep": 4, "moe_tp": 2
}]

已知限制

  • 仅支持 DeepSeek-R1、DeepSeek-V3。
  • 仅支持与 Anti-Outlier 配合；不支持 与 KV Cache Int8 同开。
  • 开启共享专家外置需要专门的「共享专家也是 W4A8」权重版本， 且必须保持开启。

收益

  • DeepSeek-R1 全量权重从 ~700 GB（fp16）→ ~200 GB（W4A8）。
  • 解码吞吐相比 W8A8 再提升 25–40%（专家层算力 + 带宽双收益）。
  • 评测精度损失 1–2 pp（取决于业务）。
